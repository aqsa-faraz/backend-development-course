# Book Store REST API

A RESTful API built with **Node.js**, **Express**, and **MongoDB (Mongoose)** for managing a collection of books.

---

## Project Structure

```text
├── config/
│   └── db.js                 # MongoDB connection setup
├── controllers/
│   └── bookController.js     # Route handlers and validation logic
├── middleware/
│   ├── errorHandler.js       # Centralized Mongoose & JSON error handling
│   └── notFound.js           # 404 route handler
├── models/
│   └── bookModel.js          # Mongoose Book schema and model
├── routes/
│   └── bookRoutes.js         # Express API routes
├── .env                      # Environment variables (not committed to Git)
├── package.json
└── server.js                 # Application entry point
```

---

## Prerequisites

* **Node.js** (v18 or higher recommended)
* **MongoDB** (Local MongoDB Community Server or a free **MongoDB Atlas** cluster)

---

## Installation

1. **Clone the repository** (or navigate into your project folder):
   ```bash
   git clone <your-repository-url>
   cd <your-project-folder>
   ```

2. **Install dependencies**:
   ```bash
   npm install express mongoose dotenv
   ```

3. *(Optional)* **Install `nodemon` for development**:
   ```bash
   npm install -D nodemon
   ```

---

## MongoDB Connection Setup

1. Create a `.env` file in the root directory of the project.
2. Add your server port and MongoDB connection URI:

   **For Local MongoDB:**
   ```env
   PORT=5000
   MONGO_URI=mongodb://127.0.0.1:27017/bookstore
   ```

   **For MongoDB Atlas:**
   ```env
   PORT=5000
   MONGO_URI=mongodb+srv://<username>:<password>@<cluster-url>/bookstore?retryWrites=true&w=majority
   ```

---

## Running the Project

* **Start the server:**
  ```bash
  node server.js
  ```

* **Start in development mode (with auto-reload):**
  ```bash
  npx nodemon server.js
  ```

Once connected, you should see:
```text
MongoDB Connected: 127.0.0.1
Server running on http://localhost:5000
```

## Book Schema

| Field | Type | Required | Validation / Default |
| :--- | :--- | :--- | :--- |
| `_id` | `ObjectId` | Auto | Automatically generated by MongoDB |
| `title` | `String` | Yes | Trimmed string |
| `author` | `String` | Yes | Trimmed string |
| `category` | `String` | Yes | Trimmed string |
| `publishedYear` | `Number` | Yes | Integer between `1000` and the current year |
| `available` | `Boolean` | No | Defaults to `true` |

---

## API Endpoints

**Base URL:** `http://localhost:5000/books`

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/books` | Retrieve all books |
| `GET` | `/books/available` | Retrieve all books where `available` is `true` |
| `GET` | `/books/search?title=<query>` | Search books by partial, case-insensitive title match |
| `GET` | `/books/:id` | Retrieve a single book by its MongoDB `_id` |
| `POST` | `/books` | Create a new book |
| `PUT` | `/books/:id` | Fully replace an existing book by `_id` |
| `PATCH` | `/books/:id` | Partially update one or more fields of a book |
| `DELETE` | `/books/:id` | Delete a book by `_id` |

---

## Sample Request Payloads

### Create or Replace a Book (`POST /books` or `PUT /books/:id`)
```json
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "category": "Programming",
  "publishedYear": 2008,
  "available": true
}
```

### Partially Update a Book (`PATCH /books/:id`)
```json
{
  "available": false
}
```

---

## Error Responses

The API returns consistent JSON error responses:

* **`400 Bad Request`**: Invalid MongoDB `ObjectId`, missing required fields, invalid `publishedYear`, unknown fields, or malformed JSON.
* **`404 Not Found`**: Book `_id` does not exist or route is undefined.
* **`500 Internal Server Error`**: Unexpected server or database failure.
