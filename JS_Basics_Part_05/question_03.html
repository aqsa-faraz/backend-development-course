Employee Data from an API

        Imagine that an API returns the following
        employee data: [
            {name:'Ali', department:'IT', salary:80000},
            {name:'Sara', department:'HR', salary:70000}, 
            {name:'Ahmed', department:'IT', salary:95000}, 
            {name:'Ayesha', department:'Finance', salary:85000}
            ]
  • Create a report containing only employees who belong to the IT department.
  • Find the first employee whose salary is greater than 90000.
  • Create a new list containing only the employee names.
  • Calculate the total salary of all employees.
  • Display the results using console.log().
  • Use arrow functions for your callback functions.
