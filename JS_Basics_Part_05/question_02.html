Student Performance Analyzer

A teacher has a list of student marks and wants to prepare a quick performance report: [45, 78, 92, 61, 88, 54, 73, 95].

  • Create a new list in which every student's mark is increased by 5 for a practice assessment.
  • Create another list containing only students whose marks are 70 or above.
  • Find the first mark greater than 90.
  • Calculate the total of all marks in the original list.
  • Display each result and keep the original marks unchanged.
  • Use arrow functions where appropriate.
