Arrow Functions and Array.isArray()

Arrow Functions

Arrow Functions allow a shorter syntax for function expressions. You can skip the function keyword, the return keyword, and the curly brackets:
const multiply = (a, b) => a * b;

Array.isArray()

The isArray() method in JavaScript is used to determine whether a given value is an array or not. This method returns true if the argument passed is an array else it returns false.
Array.isArray(obj);
